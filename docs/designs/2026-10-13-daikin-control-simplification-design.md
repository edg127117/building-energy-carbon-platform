# 大金人工控制简化修订

用户已批准本修订的代码修改和本机离线验证。它仍为活动候选，暂不部署、不调用真实控制接口。

## 约束迁移

在[此前批准设计](2026-10-11-daikin-manual-control-design.md)上，替代正常操作的逐次勾选与现场确认要求：明确受理、期限内稳定回读的操作自动结束为 `CLOUD_VERIFIED`，只表示云端核验，不表示厂家执行回执或现场物理确认。现场确认继续用于独立联调验收，以及历史 `OBSERVED_STABLE` 和异常恢复。

账号、建筑、正式身份、厂家能力、主从关系摘要、防重复发送、审计和异常隔离约束保留。控制、协议确认、测试管理员开关均默认关闭；设备与同来源控制器的在途占用限制保留，厂家行为验证前不调整并发粒度。180 秒最短观察、至少三次连续匹配且跨度 60 秒、300 秒期限保持不变。批量开放是配置许可，批量设备控制、自动策略、外机及联动控制仍排除。

## 批量设备开放

- GET `/api/v1/hvac-control/device-grants/access` 返回当前账号能否管理许可；仅当前启用的平台管理员可管理，不另设审核职责。
- POST `/api/v1/hvac-control/device-grants/batch` 接受平台设备编号 `equipmentIds`（1–100 个、不得重复）、`actions`（开关与调温的非空子集）和统一说明 `evidence`（5–500 字）；未知字段拒绝。
- 管理员按现有监测筛选结果、建筑/空间/系统组批量选择，一次提交。现有页面没有可信控制器字段，不把系统组声称为厂家控制器。
- 服务端独立只读核验每台正式身份、厂家状态、关系与当前动作能力，生成关系摘要、开关枚举和有效温度范围。已知 Master/Slave 不因角色名称单独拒绝，群控从机、关系不明或状态不可用排除并返回异常。
- 配置与审计每台独立事务提交，审计失败回滚该台，其他成功项保留；返回逐台 `opened/reasonCode/version/actions`。相同许可和说明重复提交不增加版本。同身份同关系时保留未选动作许可，关系变化不继承旧风向和其他动作证据。审计前值保留原确认说明、确认人、时间、关系与许可摘要，保留动作时不丢失原确认依据。
- 配置与发送复用来源数据库行锁；在途设备或控制器不能改许可，读取后撤权、映射变化、预检过期不能写入。控制关闭时仍可管理许可，读取共享既有监测会话和预算，管理接口不暴露厂家发送方法。
- 前端分批处理并显示进度，权限配置不自动重试。请求失败的批次显示结果未知，后续未提交项显示未处理，不能误称服务端没有保存。

## 单台操作与自动结束

`options` 增加 `currentTemperature`，由厂家只读快照给出当前设温；缺失时不猜默认业务值。调温直接调整并应用一次，开关用明确动作按钮，其他现有动作放在次级区域。每次仍提交服务端预检版本与幂等键，操作记录和测量回读分别显示。

只有 `ACCEPTED`、明确厂家受理码 `10000`、在固定期限内达到原稳定规则，才进入 `CLOUD_VERIFIED`。最后样本、状态、设备/控制器占用释放和审计在同一事务提交；写入失败保留在途占用，恢复只读核验，不重发。终态停止轮询并刷新可操作能力。

`UNKNOWN/UNCONFIRMED/CLOSED` 不因匹配自动升级成功或解除隔离，历史现场确认路径保持兼容。旧异常隔离不会因升级、新建许可或关闭记录释放。没有新增数据库结构或改写已部署 V67/V68/V69 历史。

## 部署验收待办

1. 在隔离 MySQL 验证本次新增批量许可事务、来源锁竞争和自动结束回滚，核对实际库约束与审计结果；本机 H2 不替代此项。
2. 经部署批准后备份版本、数据库和配置，记录产物哈希；仅发布测试入口 18080/18081，全部控制开关保持关闭，核对迁移历史及监测、天气、电量分析页面。启用真实控制前准备能识别 `CLOUD_VERIFIED` 的回滚版本；旧二进制不能直接读取该新终态，不通过修改历史操作来掩盖兼容问题。
3. 使用服务器只读来源验证真实设备批量预检、异常清单、授权范围、厂家频率预算和请求耗时；配置许可不自动启用控制。
4. 另获单台真实联调批准后，核对现场新基线，验证调温一次应用、稳定自动结束、下一操作可用及其他内机无联动。复验未知结果、超时、进程恢复和关开关效果。
5. 当前仅保留原控制器并发限制；厂家行为和多实例总体预算验收后再单独决定是否调整。
