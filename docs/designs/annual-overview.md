# 年度与年内累计概览

状态：已批准设计的实现候选；未部署。实际验证结果以当前任务交付记录为准。

## 查询契约

`GET /v1/energy-reporting/buildings/{buildingId}/annual-overview`

- `year`：2000—2200，必填。
- `mode`：`FORMAL_YEAR` 或 `MONTHLY_YTD`，必填。
- `throughMonth`：累计模式必填1—12；正式年度不接受。
- `timezoneId`：默认 `Asia/Shanghai`，用于确定民用日期和查询边界。

沿用月度查询的角色和建筑范围授权。查询只读，使用同一次事务的一致读取视图；不触发封账、核算或发布。

正式年度只读取当前有效的完整 `YEAR` 正式批次及冻结总排放、面积强度、人数强度，不回退为月度累计。
累计模式读取1月至截止月当前有效的月度碳批次和全楼电力封账，返回电量、电力折标煤量、碳排放和累计面积强度。
累计到12月仍称全年月度累计，不替代正式年度。电力折标煤量不代表建筑综合能耗。

各指标分别返回数值、单位、状态、缺失月份和来源批次/摘要/版本。数值为十进制字符串。
缺月时该指标总值为空，不补零、不外推、不缩短截止期。同比使用上年相同截止月份；基期为零仅返回绝对变化。
碳累计使用月度冻结未舍入汇总量，最终保留六位小数；电量和电力折标累计也保留六位小数。

## 面积期间与累计强度

`V95` 增加面积适用期间表，保留原不可覆盖的版本资料。新版本激活只替代批准区间，保留旧区间的前后部分。
部分被替代的旧版本仍有效；完全被替代的旧版本停用。人工停用移除其剩余适用区间，不回退到旧版本。
分母身份锁、区间调整、状态、依赖变更和既有审计在同一事务更新，审计保存调整前后适用区间。

迁移仅复制当前 `ACTIVE` 面积版本，不自动恢复历史停用版本。遗留重叠由查询明确报告冲突；缺失历史需要按原审批流程补齐。
用户仍只维护面积和生效日期，没有新增算法选择。建筑面积口径及来源材料由既有专业审核保证，系统不根据数值猜测专业口径。

累计平均面积 = Σ(各区间面积 × 区间实际天数) / 累计总天数。
累计面积强度 = 累计碳排放(kgCO2e) × 累计总天数 / Σ(面积 × 天数)。

使用开始包含、结束不包含的民用日期，按实际天数计算，支持闰年与月中变化；不以小时数/24计天。
面积可跨多个版本，数值相同也允许。中间不舍入平均面积，最终强度保留六位小数，单位 `kgCO2e/m²`。
面积缺口、冲突、无效数值仅使累计强度不可用，不影响完整的碳排放。面积变化本身不构成错误。

累计强度使用当前获批历史面积期间，月度排放使用当前发布结果；月度冻结面积版本不同不阻断累计。
面积纠正后累计值可变化，返回算法版本 `ANNUAL_OVERVIEW_AREA_DAY_V1`、完整面积区间及响应证据摘要。
已有月报、年报仍读取冻结结果；历史重算通过新的面积期间选择，但原月度与正式年度仍要求单一版本覆盖全期，不引入加权公式。
人数分母、正式年度/月份强度公式、原碳因子计算保持原行为。原历史设计冻结，新增累计口径仅由本文说明。

## B版接入边界

独立API和 `useAnnualOverview` 组合函数位于能源填报模块，建筑/期间切换立即清空读数，并拒绝迟到响应。
通过模块公共入口整合由B版负责方完成，本任务不修改其他工作树或公共导出。
展示时明确“年度核算”或“年内累计·截至X月”；累计面积强度读取 `YTD_AREA_INTENSITY`，不在浏览器重算。
正式年度面积强度读取 `AREA_INTENSITY`。缺失和失败显示真实状态，不回退为原型数值。

定向覆盖面积接续/局部替代/停用、闰年/月中变化、同值不同版本、缺月、同截止期同比、冻结年度、授权和请求竞争。
