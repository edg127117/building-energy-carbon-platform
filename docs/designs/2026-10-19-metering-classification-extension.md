# 总分表与多维分类扩充设计

用户于本任务批准评审方案并授权分阶段连续实施。本文记录实施契约；实现、验证和现场状态以 `PROJECT_STATUS.md` 为准。广西资料只作为适配和对账输入，不在源码、迁移或默认配置写入现场名称、倍率及公式。

## 范围与既有约束

- 扩展多套分类树、描述关联与计量归属、空间子树和交叉区域、计量去重、原生数量统计、人工来源及版本治理。
- 不扩展碳核算、收费、自动分摊、任意脚本或控制。旧单表分析、共同计量不分摊、采集身份与封账数据保留。
- 复用 `RelationGovernanceService` 的表计结构与计量分配公开契约、建筑权限与专业职责、`EnergyPeriodSnapshotReader` 的可见封账结果。分类不修改旧关系或源数据，也不把覆盖档案自动升级为专业确认。
- 分类统计只返回原生单位及来源性质，不写入另一套正式折标或碳核算结果。人工资料是独立审核的来源证据，不伪造采集历史。

## 配置整体版本

`Configuration` 包含正式关系版本引用、分类方案、节点、绑定、按品种和单位隔离的边界口径。分类方案维度为用途、部门、支路、区域或空间；模式为可加总分类或允许重叠的分析分组。分类节点无需实体表，编码稳定，父节点只能属于同一方案。

配置生命周期为 DRAFT → PENDING_REVIEW → APPROVED，撤回或退回回到 DRAFT。创建者编辑和提交；专业规则维护、审核职责及职责分离复用既有门禁。批准采用明确业务生效时刻，在建筑数据库锁内关闭旧版本有效期。整体快照不覆盖旧配置；回退通过复制旧版本并重新发布实现。并发修改使用 revision 拒绝过期写入。所有变更及审计同事务提交。

待确认绑定和口径允许随配置保存及发布，但不被解释为可计算的确认事实。没有正式关系版本时，查询返回 PENDING_EXPERT 和空值。已提交及已审核配置不可原地编辑。

## 绑定与区域

绑定对象为 POINT、EQUIPMENT、SPACE，语义为 DESCRIPTION 或 METERING。描述关联不参与计算。计量归属只从正式关系分配解析来源；`meterPointId` 可以缩小明确关联，但不能凭空指定不覆盖该对象的电表。

空间绑定按所引用关系版本的空间子树展开，设备绑定只使用正式计量覆盖，不将安装位置推定为被测位置。同一来源经设备和测点重复关联按片段去重。共用计量不拆成单台实测值。

独立统计区域通过分类节点及成员绑定表达，可跨楼层。可加总方案内出现互不包含的多重归属时保留未分配并提示冲突；重叠分组允许同一片段出现在多个组，但不能把组值求和充当总量。联合筛选必须具有计量片段层面的交集证据；缺少归属时返回 UNDETERMINED。

## 计算与来源

1. 固定完整期间内有效的分类版本和正式关系版本。跨分类或关系生效边界拒绝混算，要求按边界分段；不按时间比例猜分配。
2. 读取相同能源品种、单位、期间的可见封账来源及独立审核人工来源。重叠来源不自动择一或相加；有缺口则明确不完整。
3. 按边界口径选总表、最上层分表或独立表，沿父子链排除祖孙重复。上下级跨边界或方向、循环及缺失引用拒绝计算。
4. 逐层以父表减直接子表形成互不重叠片段。子表缺数保留差额未知性质；负差额保留诊断并停止该范围分解，不取绝对值、不命名为电损。
5. 每套分类独立解释同一片段。分类路径上父子绑定只贡献到最具体节点，再向祖先回卷。同维度冲突不影响其他维度事实，但相关报表会提示。
6. 输出节点用量、原生单位、计量来源、差额、版本、证据、完整性和来源性质。没有独立测量的节点为空，不生成零值。

同设备存在多个非上下级计量通道时，默认阻止合并；确属独立通道须在边界规则显式确认并携带证据、经过配置审核。上下级通道仍按计量树去重，不以设备名称或测点后缀判断重复。

分表求和保守标为 MEASURED_SUBTOTAL，其他确认口径为 BOUNDARY_TOTAL，均不自动宣称全楼覆盖。出入方向保留于计量结构和对账，原生净数量按方向取符号。

人工导入支持明确期间量或累计起止读数、倍率、已换算标志、EXACT/DATE_ONLY 时间精度及来源引用。已换算值禁止再次乘非一倍率；未分类负增量只能待确认。日期精度累计量不用于精确期间统计。确认来源的品种、单位和期间必须与有效能源品种绑定一致。

导入使用建筑内幂等键和内容哈希，预览不写入。导入后 PENDING_REVIEW，经独立异常审核职责批准才可统计。重复或重叠期间在审核时拒绝；修订必须明确 supersedesFactId，保持测点、期间、品种和单位一致，旧证据保留，只有最新已批准修订参与统计。

## 入口与容量边界

- `/v1/energy-classification/buildings/{buildingId}` 提供版本、查询、读数预览、导入、审核和历史。
- 页面复用已有分项及分区菜单叶子授权；没有额外隐式授权。既有关系维护接口继续负责真实计量结构。
- 每次导入最多500条，查询最多366天、5000条来源及关系；超限拒绝并提示缩小范围。不得静默截断。
- 原电力监控在数据库分页前按正式分类筛电表，分页使用服务端总数；相制及覆盖数量明确为当前页，避免前100台设备造成遗漏。
