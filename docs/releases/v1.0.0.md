## 后续开发与回读

后续任务从包含 `v1.0.0` 的最新 `origin/main` 开始，以继承平台阶段成果和后续已合入的工作。精确回读阶段快照时使用 `v1.0.0`：

```powershell
git fetch origin main
if ($LASTEXITCODE -ne 0) { throw '获取主线失败' }
git fetch origin tag v1.0.0
if ($LASTEXITCODE -ne 0) { throw '获取平台版本标签失败' }
git merge-base --is-ancestor v1.0.0 origin/main
if ($LASTEXITCODE -ne 0) { throw '主线未包含平台 V1.0，停止创建任务分支' }
git switch -c feature/next-task origin/main
if ($LASTEXITCODE -ne 0) { throw '任务分支创建失败' }
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Invoke-TaskPreflight.ps1
```

在干净工作区执行，任务名替换为实际名称，预检必须返回 `TASK_PREFLIGHT_OK`。查看全平台后续差异使用 `git diff v1.0.0 origin/main`。如需独立回读，在新目录克隆：

```powershell
git clone --branch v1.0.0 https://github.com/edg127117/building-energy-carbon-platform.git building-energy-carbon-platform-v1
```

标签源码中的旧归档名称是当时记录，本文件和平台 Release 提供更正解释。代码回读不重置当前开发目录，不回滚运行环境；恢复性开发仍通过任务分支和 PR 交付。
