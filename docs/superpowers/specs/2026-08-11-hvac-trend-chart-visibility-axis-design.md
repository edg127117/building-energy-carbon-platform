# HVAC 历史趋势图可见性与纵轴修复设计

> 状态：已确认并完成书面复核。本设计只修复历史趋势图中孤立 Q0 点不可见、纵轴单位位置异常和全空数据缺少明确状态的问题，不改变后端历史数据、质量等级或缺口语义；实际完成状态继续以当前代码、测试和 PR 为准。

## 1. 背景与问题

当前 [`HvacTrendChart.vue`](../../../web/src/components/hvac/HvacTrendChart.vue) 保持缺口断线，并按 Q0/Q1/Q2 展示数据质量。但现有展示策略存在两个确定缺陷：

1. Q0 数据项始终使用 `symbol: none`。当一个 Q0 点两侧都没有有效点时，它既不形成线段，也没有点标记，最终在图中完全不可见。
2. 单位被移到 Canvas 外单独显示，ECharts 的 `yAxis.name` 被移除。整组 `average` 都为 `null` 时，ECharts 也不会生成 y 轴数值刻度，页面只剩横轴和范围条，视觉上像图表损坏。

现有测试明确断言 Q0 为 `none`、`yAxis.name` 不存在，因此必须同步修正实现与测试，不能只调整 CSS。

## 2. 目标

- 孤立的 Q0 真实点必须可见。
- 连续或高密度 Q0 曲线继续以线为主，不给每分钟都增加圆点。
- 缺口继续断线，不用连接缺口掩盖数据缺失。
- 工程单位回到真正的纵轴语义中，并避免与图例、刻度或画布重叠。
- 全组没有有效值时显示明确空状态，不伪造数值和坐标范围。
- 保持现有系列显隐、Tooltip、DataZoom、响应式和无障碍职责。

## 3. 不包含范围

- 不修改后端 API、DTO、TDengine 查询或质量计算。
- 不改变 Q0/Q1/Q2 的业务含义。
- 不进行前端插值、补点、指标重算或虚假默认值填充。
- 不连接跨桶缺口。
- 不重做历史面板、时间选择器或整页视觉风格。
- 不修改其他图表或 Dashboard 模块。

## 4. 方案选择

### 4.1 采用方案：按可见性显示 Q0 + 正常纵轴 + 真实空状态

- 只有当前 Q0 点两侧都没有相邻有效值时，才显示实心圆点。
- 只要任一侧存在相邻有效值，当前 Q0 已能通过线段被看见，不再增加圆点。
- Q1 继续使用圆点，Q2 继续使用菱形，空值和未知质量不冒充真实点。
- 工程单位重新配置到 `yAxis.name`；系列图例继续保留在 Canvas 外，避免恢复旧的图例重叠问题。
- 全组没有任何有限数值时显示“当前时段无有效数据”，不提供虚假的 0～1 或业务默认刻度。

该方案同时保留数据真实性和高密度趋势图的可读性，是本任务的确认方案。

### 4.2 未采用：所有 Q0 都显示圆点

实现简单，但一分钟分辨率下会产生大量密集标记，降低折线和 Q1/Q2 异常质量点的辨识度。

### 4.3 未采用：连接缺口或给空图固定坐标范围

连接缺口会把无数据时段伪装成连续趋势；固定坐标范围会在没有事实数据时制造误导性尺度，均违反前端不伪造业务数据的边界。

## 5. 详细行为

### 5.1 有效点与相邻线段

有效点定义为 `average` 是有限数字；`null`、`NaN` 和无穷值均不参与折线或坐标范围。

对序列中每个数据项：

- 当前值无效：`symbol: none`；
- Q1：`symbol: circle`；
- Q2：`symbol: diamond`；
- Q0 且前一个或后一个数据项有效：`symbol: none`；
- Q0 且前后都没有有效数据项：`symbol: circle`。

“相邻”只看数组中的直接前后项。领域适配层已经在跨桶处插入空分隔点，因此该规则不会跨缺口寻找更远的数据并误判为连续线段。

### 5.2 纵轴单位与布局

- `yAxis.name` 使用当前组单位；空单位显示“无量纲”。
- 单位采用与现有轴标签一致的弱化颜色，不替代数值刻度。
- 系列图例继续位于 Canvas 外，纵轴单位不再使用独立 DOM 行重复展示。
- 调整图表 `grid`、顶部留白和标签包含策略，确保单位、y 轴数值、x 轴时间及范围条均不被裁剪。
- 同单位系列继续合并在一张图并共用一个纵轴；纵轴范围取当前查询时段内该组全部系列的有限有效值，不因系列名称分别设置固定量尺。
- 有两个及以上不同有效值时继续使用 ECharts 数据驱动范围；即使单位为 `%`，也不得固定成 `0～100` 或其他业务默认范围。
- 只有一个不同有效值时，以该值为中心建立小幅数据驱动留白，避免 ECharts 自动扩展出过宽且难读的范围；留白不得替代或修改原始数值。

### 5.3 全空与部分空数据

- 全组没有有限值：保留标题、质量图例、系列图例和单位，图表区域显示“当前时段无有效数据”；不显示伪造的 y 轴刻度。
- 只有部分系列为空：有效系列正常绘制，空系列仍保留显隐入口，不影响同单位其他系列的坐标范围。
- 空状态必须是 DOM 可读文本，不能只绘制在 Canvas 内；屏幕阅读器和截图都能明确识别。
