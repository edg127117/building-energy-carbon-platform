# 配置与填报简化：本轮变更与软件验收

日期：2026-10-22。范围依据：[已批准方案对应的实施设计](../../designs/2026-10-22-energy-reporting-simplification-design.md)。本记录只说明软件候选与独立环境证据，不构成现场验收、部署授权或正式版本批准。

## 交付变化

| 职责 | 本轮结果 |
| --- | --- |
| 业主 | 选择授权建筑与月份，填报或导入原始用量及凭证，预检后提交；单位和方法继承服务端，专业参数只读。 |
| 实施人员 | 独立维护账单/人工统计来源、主来源及覆盖依据。无实体总表时不伪造设备或测点，批准来源只通过明确的新版本替代。 |
| 平台专业人员 | 通过B01/B02目录、来源、地区/年份/适用期预检和分条导入建立待审核版本，继续使用原独立审批、激活和分母治理。 |
| 独立审核人 | 审核来源和数据、核对量化排除及凭证，再封账；来源或参数依赖改变须退回重审。 |
| 平台计算 | 原生量、折标煤和碳分别判断完整性；同源只计一次，单位只归一一次；账单没有分项时显示未分配总量，修订保留旧快照和报告。 |

范围一固定源、范围二外购电/热及量化碳排除纳入；水与绿色能源仅预留。移动源、标油、金额估算算法、跨期自动拆分/平摊和比例推算排除量不纳入。原表计链和专业工作区保留。

V84新增独立账单/参数包锁、记录和回执；V85仅登记热力CO2代码公式，不创建实际因子、不配置楼宇、不授予后台职责。没有修改部署脚本、运行控制状态或空调控制业务。

## 证据与复核

[脱敏证据JSON](evidence/2026-10-22-reporting-simplification.json)保存普通套件统计、相关用例、门禁结果、隔离联调摘要、局部日志摘要哈希及79个代码/测试文件指纹。源码指纹按UTF-8文本统一CRLF为LF后计算SHA-256，便于在PR检出后核对。指纹定位对应源码，不替代执行测试。

原始日志、JWT/密码、数据库文件、SQL备份、本机地址、临时浏览器与运行脚本不进入Git。独立应用、MySQL及3个专用容器已经关闭；没有操作共享测试服务器或其他任务服务。

## 保留边界

- 本候选没有部署，也没有改变实际楼宇配置、后台职责、空调控制状态或既有控制业务逻辑。
- 真实来源覆盖、普通体积/标准体积条件、因子地区/年份及面积人数仍须依据项目事实和独立审核确认。金额折算资料保留其真实性质，不能直接冒充原始实物量。
- 广西大楼等待正式资料；创新港只保留配置草稿和待确认事实，不自动发布生效。
- 其余按条件跳过的外部/硬件场景、生产发布、现场设备和长期容量尚未验收。以后部署需独立备份、迁移和发布核验，不能仅靠回切应用回滚数据库。
